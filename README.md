# TAGINTELL - Farm Stress Detection Platform

AI-powered satellite intelligence for precision agriculture.

## Features

- 🌾 **Multi-Index Analysis**: NDVI, NDWI, NDRE for comprehensive stress detection
- 🎨 **Visual Stress Maps**: Color-coded satellite imagery
- 💬 **Farmer-Friendly**: Plain language alerts and actionable recommendations
- 🛰️ **Sentinel-2 Powered**: high-resolution satellite data

## Stress Detection

- **Water Stress**: Detects irrigation issues
- **Nutrient Stress**: Identifies fertilizer needs
- **General Stress**: Flags other crop health issues

## Tech Stack

- **Backend**: FastAPI + Python
- **Satellite**: Google Earth Engine (Sentinel-2)
- **Deployment**: Render (Backend), Vercel (Frontend - coming soon)
